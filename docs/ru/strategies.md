# Стратегии и отображение на zapret

*Профиль* — это переносимое описание стратегии обхода в Deimos. Оно намеренно близко к
словарю самого zapret, но никогда не генерирует флаги вслепую: каждый профиль можно
предварительно просмотреть перед использованием.

```bash
deimos profiles preview tls-split
```

```text
C:/zapret/binaries/windows-x86_64/winws.exe --wf-tcp=443 --filter-tcp=443 --filter-l7=tls \
  --dpi-desync=split2 --dpi-desync-split-pos=1 --dpi-desync-autottl=2
```

## Раунды

Профиль содержит один или несколько *раундов*. Каждый раунд — это фильтр плюс описание
десинхронизации, то есть ровно набор правил zapret, разделённых `--new`.

```json
{
  "filter": { "tcp": [443], "udp": [], "l7": ["tls"] },
  "modes": ["fake", "split2"],
  "splitPos": 1,
  "fooling": ["md5sig"],
  "autoTtl": 2,
  "repeats": 6
}
```

## Отображение полей

| Поле профиля | winws / nfqws | tpws |
| --- | --- | --- |
| `filter.tcp` | `--filter-tcp=443` (winws также добавляет его в `--wf-tcp`) | `--port=443` |
| `filter.udp` | `--filter-udp=443` (winws также добавляет `--wf-udp`) | не поддерживается |
| `filter.l7` | `--filter-l7=tls` | не поддерживается |
| `modes` | `--dpi-desync=fake,split2` | `--split-pos`, `--disorder` |
| `splitPos` | `--dpi-desync-split-pos=1` | `--split-pos=1` |
| `splitSeqOverlap` | `--dpi-desync-split-seqovl=N` | предупреждение, игнорируется |
| `fooling` | `--dpi-desync-fooling=md5sig` | предупреждение, игнорируется |
| `ttl` | `--dpi-desync-ttl=N` | предупреждение, игнорируется |
| `autoTtl` | `--dpi-desync-autottl=N` | предупреждение, игнорируется |
| `repeats` | `--dpi-desync-repeats=N` | предупреждение, игнорируется |
| `windowSize` | `--wssize=N` | не поддерживается |
| `fakePayload` | `--dpi-desync-fake-tls=<file>` или `--dpi-desync-fake-tls=@0x<hex>` | н/д |
| `hostlists` | `--hostlist=<file>` (tpws: `--hosts`) | `--hosts` |
| `hostlistExcludes` | `--hostlist-exclude=<file>` | `--hostlist-exclude` |
| `ipsets` | `--ipset=<file>` | `--ipset` |
| `extraArguments` | добавляются дословно | добавляются дословно |

Опция поддельной полезной нагрузки выбирается по L7-фильтру раунда: `quic` использует
`--dpi-desync-fake-quic`, `http` — `--dpi-desync-fake-http`, `tls` —
`--dpi-desync-fake-tls`, а раунд только с UDP и без L7-фильтра по умолчанию использует
QUIC.

## Раскладка процессов по инструментам

| Инструмент | Процессы | Примечания |
| --- | --- | --- |
| `winws` | один | Раунды разделяются через `--new`; предварительный фильтр WinDivert (`--wf-tcp`/`--wf-udp`) — объединение портов всех раундов, если профиль его не переопределяет |
| `nfqws` | один на раунд | `--qnum` начинается с `profile.nfqueue` и увеличивается на каждом раунде |
| `tpws` | один на раунд | Только TCP; существуют лишь семантики split и disorder |

`tool: "auto"` разворачивается в `winws` на Windows и в `nfqws` на других платформах, с
откатом на любой обнаруженный инструмент.

## Валидация

`buildLaunches()` проверяет каждый раунд перед генерацией аргументов, поэтому одни и те
же правила действуют для предпросмотра через API, для CLI и для движка:

- в раунде должен быть хотя бы один порт;
- `ttl` должен быть 1..255, `autoTtl` — 1..32, `repeats` — 1..32;
- встроенные фиктивные полезные нагрузки должны быть шестнадцатеричными строками чётной
  длины;
- `disorder` без флагов fooling, TTL или autottl вызывает предупреждение, поскольку
  пакет редко доходит до сервера неизменённым;
- больше двух режимов десинхронизации в раунде подозрительно;
- раунды tpws с режимами fake, UDP-портами или дополнительными опциями порождают ошибки
  или предупреждения;
- `--new` внутри `extraArguments` отклоняется, так как раунды уже его добавляют.

Уровень `error` блокирует запуск; предупреждения показываются и игнорируются.

## Стартовые профили

Сгенерированная конфигурация содержит два профиля, которые можно использовать как
отправную точку:

| Id | Назначение |
| --- | --- |
| `tls-split` | Разделяет TLS ClientHello на порту 443, чтобы обойти инспекцию SNI |
| `quic-split` | Отвечает на пакеты QUIC Initial поддельным пакетом, чтобы сломанное видео переходило на TCP |

Они намеренно консервативны. Поведение DPI в реальности зависит от провайдера;
настраивайте их с помощью предпросмотра, потока журналов и `endpoints` из собственных
пресетов zapret.

## Где ищется zapret

Обнаружение пробует по порядку: `zapret.installDirectory`, `$DEIMOS_ZAPRET_DIR`, каталог
рядом с `deimosd`, рабочий каталог, `%ProgramData%/zapret`, `%ProgramFiles%/zapret`,
`/opt/zapret`, `/usr/local/zapret`.

Внутри каталога-кандидата Deimos просматривает `bin/`, `binaries/<platform>/`, корень и,
наконец, выполняет ограниченный поиск в глубину. Имена инструментов — `winws`, `nfqws` и
`tpws` (`winws.exe` на Windows). Относительные пути hostlist разрешаются относительно
дерева zapret, поэтому стандартная раскладка zapret с `lists/` и `files/` работает без
изменений.
